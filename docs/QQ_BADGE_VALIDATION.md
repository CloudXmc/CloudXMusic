# QQ 徽章坐标与边缘修复 · 2026-11-15

版本保持 `2.6.0-alpha.3`。本次以用户实机截图的两处标记为依据，仅调整 UI 绘制。

## 修改与原因

- `QQLoginPainter`：账号 SVIP6 徽章调用按可见字形边界计算的居中绘制；文字左边缘为 `背景 X + (背景宽度 - 可见文字宽度) / 2`，扣除字体侧承后定位字形原点。垂直方向按可见高度居中，消除固定基线与阴影带来的偏移。描边固定为内收的 1px，并恢复原 Stroke。
- `QQVipBadge`：保留原有标题截断与测宽，徽章起点仍为实际显示标题结束位置加 8px；新增底栏使用的无描边绘制分支，圆角填色，文字居中。文字使用局部 Graphics2D，显式 SrcOver 后释放，不污染调用者合成状态。
- `MusicPainter`：只有播放条标题调用切入无描边分支。其他列表仍沿用原有徽章样式。未改字体资源、曲名、会员判定或任何业务数据。

本轮生产源码改动严格限定上述三个文件。登录、持久化、搜索、权限、取链、队列、声卡、解码、网络请求与生命周期均无本轮改动；网易云包不修改。截图仅用于视觉参考，不作为账号或业务数据输入。

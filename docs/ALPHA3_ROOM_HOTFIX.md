# 2.5.0-alpha.3 QQ 房间播放紧急修复

工作目录：`F:\Codex\CloudXMusic\v2.5.0-alpha.3`。Minecraft 1.21.11 Fabric 客户端，Java 21，GPL-3.0-only。版本保持 2.5.0-alpha.3。

## 根因与处理

- 房主 tick 原先把 QQ 本地加载/暂停、解码进度、循环模式重新转换成控制包，形成反向广播。QQ 路径现在只同步显式队列编辑和 30 首滑动窗口，播放时间轴只消费服务端消息。
- `MusicRoomClient.receive` 对相同播放快照及同曲同状态的小幅进度差直接忽略，带防重入和回调期间禁止发送控制包的保护。周期位置心跳校准房间钟，不等同于用户 seek。
- 新的 `QQRoomPlaybackBridge` 只消费状态、不发送网络包。房间曲目的临时解码会话与个人完整队列分开；启动时一次性带入服务端位置，避免先播放再 seek 的双重取链。
- 房间内 QQ 曲末和无资源失败不再本地切歌或单曲重播，等待服务端下一首。个人循环模式不写回房间；房间图标和模式使用服务端值。
- QQ 漂移超过 4 秒才 seek，漂移纠偏冷却 10 秒；服务端明确时间轴变化的 seek 合并并限制至至少 3 秒。加载、错误、seek 进行中和自然结束时不周期重启。
- QQ 解码器曲末事件只由房主解释：单曲循环对当前 MID 发 `JUMP + SEEK(0) + PLAY`，列表循环从完整队列回绕，随机模式挑选另一 MID；听众不计算下一首，收到服务端时间轴后才起播。同 MID 回零按新播放代次识别，短曲不会被相同消息去重或 seek 冷却吞掉。
- QQ 声卡在成功写出首个 PCM 块后触发一次 started 回调；控制器按播放代次过滤晚到事件，听众清除旧的 UNAVAILABLE 状态并上报 LISTENING。日志包含 `[房间听众] 音频流已启动，清除错误提示` 和 `[房间UI] 状态更新为正在播放`。
- 只有 QQ 网络/取链不可用路径会把房间成员标记为 UNAVAILABLE；声卡输出故障不再伪装为歌曲版权或鉴权失败。
- QQ 封面请求记录不含查询参数的 HTTP 状态、主机与路径，专辑图地址最多后台尝试三次（含小尺寸和备用 CDN），头像只重试临时失败；结果入缓存后递增 revision 并触发界面静态层重绘，失败缓存到期后由客户端 tick 重新排队。
- 暂停期间取消正在取链的会话并撤销音频播放许可；晚到结果不能启动旧歌曲。
- QQ 全页面底栏、空格键、队列行、搜索和歌单播放请求统一走房间权限/服务端请求。听众不能增删队列、切歌或更改房间模式。
- 搜索、收藏和队列的增删提示使用 Minecraft 原生 `SystemToast`，文案分别为“已添加到播放队列”和“已从播放队列移除”。源码内不存在 `QQNotificationManager`。

## 线程与生命周期审查

| 分类 | 入口与调用链 | 线程边界和清理 |
| --- | --- | --- |
| must_fix，已处理 | Custom Payload → 客户端线程 receive → 房间快照 → follower → QQ bridge | 回调只更新快照，不能反向控制服务端；bridge 防重入且按 MID/播放意图去重 |
| must_fix，已处理 | QQ decoder EOF/取链失败 → 客户端回调 | 房间模式停止本地自动跳歌；离开房间停止临时音频并释放桥接状态 |
| must_fix，已处理 | GUI/空格/目录播放 → 房间权限 → QueueSet/PlaybackControl | 用户操作只发请求；收到服务端广播后才切换本地播放 |
| 已复用 | QQ 取链 → 有界后台执行器 → 客户端回调 → 声卡执行器 | 继续使用原来的代次许可、异步 HTTP Range 请求、解码器重建和声卡缓冲清理；不在游戏线程同步等待 |

本轮没有修改网易云、MusicState、公共音频底层、PacketCodec 或协议 JAR。没有新增 Bukkit/Paper/Folia API；服务端源码不在此源码包内。

## 验证与实机验收范围

上一轮新增 20 项回归覆盖：直接编码/解码房间广播并验证无反向发包、滑动窗口、相同广播、加载中暂停、失败歌曲、曲末、个人模式隔离、限频 seek、删除最后一首、真实 FLAC/MP3 解码结束等。本轮新增播放首帧和会话代次、所有房间 repeat 模式 EOF、服务端暂停恢复、成员状态恢复、短曲循环识别、封面状态码重试及迟到元数据同步回归。

最终执行 `gradlew.bat clean build --no-daemon`。测试数量与产物 SHA-256 以交付记录为准。

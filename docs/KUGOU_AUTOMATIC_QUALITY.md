# 酷狗自动音质定稿 · 2026-11-16

版本保持 `2.6.0-alpha.3`，Java 21 / Minecraft 1.21.11 Fabric 客户端，许可证沿用 GPL-3.0-only。

## 当前行为

- 底栏不绘制酷狗音质胶囊；原位置点击不触发音质操作。移除酷狗菜单绘制类及音质菜单中的 VIP / SVIP 标签。账号及歌曲的会员徽章保留。
- 音源切换时关闭旧菜单；菜单绘制、选择与悬停入口均排除酷狗。网易云与 QQ 的音质组件、坐标和业务保持原样。
- 已登录时先请求 Web `/play/songinfo`，不传 quality。对服务端返回的音频做完整曲目、CDN 域名、格式与真实音频头验证，接受第一个可播结果。
- Web 无可用结果时尝试 App 320，再尝试 128；同路由支持带专辑信息和 hash-only。游客保留 App 路径。CDN 拒绝、网络失败和空资源允许继续兜底；明确登录失效、设备验证、整首锁定仍停止该次取链。
- 不再为自动选中的音质发送“已降级”提示；实际音质仍保留在内部快照和脱敏日志中。旧 library.json 音质字段保留兼容，不干预播放，也不在启动时触发音质重载。
- 保留 KRC、搜索、收藏完整队列、互斥交接、拖拽状态锁、Range/If-Range、缓冲重建及后台 drain。该次不修改独立音频引擎或其他两源底层。

## 参考与限制

取链采用 Web 优先、App 320 / 128 兜底。当前集成无法稳定取得无损 / Hi-Res，不能根据账号 VIP 标识推断可取得的具体音质，也未确认 kg_dfid 是唯一成因。

服务端决定 Web 实际返回的资源；这不保证返回账号可用的绝对最高规格。网络断开、版权及账号权限、设备验证仍可能导致无法播放。本次未执行会员领取或权限绕过，也未新增账号写接口。

## 验证与回退

先运行回归测试，确认 8 项因旧行为失败，再修改实现。目标回归覆盖明暗主题及 1× / 1.5× 缩放下的胶囊隐藏、命中区域、其他源按钮保留、Web 立即返回、旧标准偏好不跳过 App 320、320→128、试听 / 非支持格式 / CDN 拒绝恢复、网络失败分类、整首锁定与防抖、拖拽、账号代次和声卡互斥。

全量构建日志、JUnit 汇总、生产文件隔离核对、成品清单与 SHA-256 随交付目录提供。源码 ZIP 包含本次修改、测试、许可证、资源和现有构建所需 libs，排除真实账号、运行数据、outputs 与构建缓存，并逐文件校验归档内容。

修改前源码与 JAR 备份位于本地 `outputs/kugou-auto-quality-20261116/before-source.zip` 与 `before.jar`；保留原工作区全部已有改动。

- `defer`：真实 Minecraft / Fabric 中的连续播放、账号返回与真实声卡听感验收，待安装此版本测试；酷狗音乐房间按用户要求继续禁用。
- `uncertain`：平台对不同账号、歌曲、地区和设备校验返回的实际音质及稳定性。本次未重新调用真实账号接口，采用固定响应、回环 HTTP 和真实测试音频验证。
